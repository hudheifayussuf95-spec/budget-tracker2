
# Personal Budget & Expense Tracker

## Project Description

The Personal Budget & Expense Tracker is a simple website
developed using HTML and CSS.

The purpose of this project is to help users organize
and track their daily expenses.

## Technologies Used

- HTML5
- CSS3
- Visual Studio Code
- Git and GitHub

## Project Features

### 1. Website Header
Displays the website logo, title and description.

### 2. Add Expense Form
Contains:
- Expense Name
- Amount (KES)
- Category dropdown
- Expense Date
- Add Expense button

### 3. Expense Table
Displays five sample expenses with:
- Name
- Amount
- Category
- Date

### 4. Multimedia
Includes a logo image and an embedded YouTube
budgeting tutorial.

### 5. Interactive Elements
Uses HTML details and summary elements to
create collapsible instructions.

### 6. CSS Styling
Uses:
- Element selectors
- Class selectors
- ID selectors
- Descendant selectors
- Direct child selectors
- Hover effects
- Focus effects
- nth-child selectors
- Negation selectors

## Project Files

- index.html - Website structure and content.
- style.css - Website design and styling.
- README.md - Project documentation.
